## 一、唯一的错：`reserve` 漏了返回类型

```
类练习2-填空.cpp(76): error C4430: 缺少类型说明符 - 假定为 int。注意: C++ 不支持默认 int
类练习2-填空.cpp(76): warning C4183: "reserve": 缺少返回类型；假定为返回"int"的成员函数
类练习2-填空.cpp(77): error C2561: "Vec::reserve": 函数必须返回值
```

你写的是（第 76 行）：

```cpp
    reserve(int newCap) {          // ❌ 前面少了 void
```

应该写：

```cpp
    void reserve(int newCap) {     // ✅
```

**为什么会连报三条**：

1. `C4430`：C++ 里**函数必须写返回类型**。老 C 语言有个"不写就默认 int"的规矩，C++ 把它废掉了 —— 所以编译器说"我假定它是 int，但这是错的"
2. `C4183`：同一个原因的警告版（"我假定你返回 int 了"）
3. `C2561`：既然假定返回 `int`，函数里那句 `return;`（空 return，什么也不返回）就矛盾了 —— 编译器要求"必须返回值"

**一个字母（`void`）带出三条报错**，还是那个老规律：**只看第一条**。

> 我记得你 A9 也踩过一次同一类：那次是 `int* fresh = newCap;`（少了类型和方括号）。
> 这两次的共同点是：**声明/定义的最前面那几个关键字，容易被当成"不用写"**。
> 小习惯：写完一个函数，先看开头有没有"返回类型 + 名字 + 括号"这三样。

## 四、改完的样子（就一行）

```cpp
    void reserve(int newCap) {
        if (newCap <= cap_) return;
        int* fresh = new int[newCap];
        for (int i = 0; i < size_; i++) fresh[i] = data_[i];
        delete[] data_;
        data_ = fresh;
        cap_ = newCap;
    }
```
