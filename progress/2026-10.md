### C++ 基础自测（指针 / 数组 / new-delete）

- 自测 A1–A3 答对；A4（数组传参退化）、A5（`new`/`delete` 配对）部分答对，已批改
- 今天真正搞清楚的三件事：
  1. **数组名传参会退化（decay）** —— `int arr[5]` 的 `5` 只是给程序员看的，形参类型会被改写成指针，
     所以函数里 `sizeof(arr)` 是 8（指针大小）而不是 20；长度只能另外传参数
  2. **`new[]` 会偷偷记一个"元素个数 cookie"** —— `delete[]` 靠它知道要析构几次；
     `delete` 不认这个 cookie，对带析构函数的类型会少析构 + 堆损坏崩溃（反汇编里能看到 `lea rbx,[rcx-8]`）
  3. **`%zu` 是 `size_t` 的正确格式符** —— 写 `%d`/`%u` 只是"碰巧对"，换平台或数值变大就出错

`grow` 的五步顺序（关键：顺序错就是悬垂指针或内存泄漏）：

```cpp
int* fresh = new int[newcap];        // ① 申请 cap*2 的新内存
for (i...) fresh[i] = old[i];        // ② 把前 size 个搬过去
cap = newcap;                        // ③ 更新容量（cap 是引用）
delete[] old;                        // ④ 搬完才能释放旧的
return fresh;                        // ⑤ 返回新指针
```

### 这轮踩的四个坑（都是经典，记下来）

1. **`for` 三段用分号，不是逗号** —— 写成 `for(i=0 , i<n, ++i)` 编译器会报"i 重定义"
2. **全角标点**（`；，''`）编译器不认（报 `C3872/C3873`）→ 写代码前切英文半角
3. **`new int{7}` 是"一个" int，`new int[7]` 才是数组** —— 花括号是初值，数组必须方括号
4. 拼写：`fersh`→`fresh`、`oid`→`old`
