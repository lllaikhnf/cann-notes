## 二、5 处要改的（按重要性排）

### ① 第 17 行：`cost` → `const`（一个字母，带出 4 条报错）

```cpp
bool byLevelDesc(cost Player& a, cost Player& b) {     // ❌ cost
bool byLevelDesc(const Player& a, const Player& b) {   // ✅ const
```

`cost` 不是类型名，编译器一懵，就顺着往下报了 4 条（缺 `)`、缺 `;`、缺函数头）。

**并且它还带出了第 76 行那条** `byLevelDesc 未声明`——因为你那个函数**定义失败了**，
等于从没定义过，main 里自然找不到它。所以第 76 行**不用改**，改完第 17 行它自己就没了。

> 这就是"**一个错误带出一串**"的典型。下次看到一屏红字，先处理最上面那条。

### ② 三个 `})` 后面都漏了 `;`（同一个动作连错三次）

第 85、108、115 行都是这个形状：

```cpp
    std::sort(c, c + n, [](const Player& p, const Player& q) {
        return p.score < q.score;
    })          // ❌ 这里少一个分号
```

`})` 看着像"写完了"，其实**整个 `std::sort(...)` 语句还没结束**——要一个 `;` 收尾：

```cpp
    });
```

编译器报的位置是**下一行**（`show` 前面缺 `;`），因为它是读到 `show` 才发现"上一句没结束"。
**报错行号 ≠ 出错行号**，这条在 A7 也吃过一次。

### ③ 第 84 行：`p < q` —— 这是 A7 那个错误**第二次**踩

```cpp
    return p < q;                 // ❌ Player 没定义 < 运算符
    return p.score < q.score;     // ✅ 比的是分数
```

错误原文 `error C2676: 二进制“<”:“const Player”不定义该运算符`——
A7 那次是 `error C3889`（`std::sort` 默认比较器要求 `operator<`），**同一个知识点**：
**`Player` 是你自己 struct 的，编译器不知道两个 Player 谁大谁小，必须你告诉它比哪个字段。**

记法：**"结构体不会自己比大小，比较规则永远要写出来。"**

### ④ 第 114 行：`dsec` → `desc`

```cpp
    return dsec ? p.score > q.score : p.score < q.score;   // ❌ dsec
    return desc ? p.score > q.score : p.score < q.score;   // ✅ desc
```

`dsec` 没定义过（捕获列表里捕获的是 `desc`）——**差两个字母的顺序**。
顺带说：`[desc]` 这个捕获你**写对了**，两次都写对了。

### ⑤ 逻辑错：三元运算符的方向反了（编译器抓不到，得自己看出来）

你两处都写成：

```cpp
    return desc ? p.score < q.score : p.score > q.score;
```

意思是：`desc = true` 时按**升序**，`desc = false` 时按**降序**。
但注释和输出写的是：「**desc = false：分数升序**」「**desc = true：分数降序**」——**正好反了**。

正确是：

```cpp
    return desc ? p.score > q.score : p.score < q.score;
    //            ↑ true 走降序          ↑ false 走升序
```

> ⚠️ 注意：**这个错编译不会报，自检也不一定抓得到**（最后自检只看 `d` 的最终状态）。
> 从哪看出来？看**运行输出**里那一行 `=== 带捕获 [desc]，desc = false：分数升序 ===` 底下的顺序——
> 如果它是从 95 往下排的，说明方向反了。**输出要逐行看，不能只看最后那行"自检 ✅"。**

## 四、改完的完整样子（照这个核对）

```cpp
// ①
bool byLevelDesc(const Player& a, const Player& b) {
    if (a.level != b.level) {
        return a.level > b.level;
    }
    return a.score > b.score;
}

// ② TODO 3（补分号、改成比 score）
    std::sort(c, c + n, [](const Player& p, const Player& q) {
        return p.score < q.score;
    });

// ③ TODO 4 两处（补分号、dsec→desc、三元方向反过来）
    std::sort(d, d + n, [desc](const Player& p, const Player& q) {
        return desc ? p.score > q.score : p.score < q.score;
    });
```
