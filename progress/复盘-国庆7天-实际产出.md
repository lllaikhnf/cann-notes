## 三、这 7 天踩过的坑（按价值排序）

| # | 坑 | 教训 |
| --- | --- | --- |
| 1 | **中文乱码「三层编码」**：源文件编码 → 编译器 `/utf-8` → 控制台代码页 | 三层任意一层不对，中文就变鬼。已写成笔记第十七节 |
| 2 | **编辑器缓冲区 ≠ 磁盘**：编辑器里改了没存盘，VS 编的是磁盘上的旧文件 | 改完必须 Ctrl+S；"看着对"不算数 |
| 3 | **结构体没有 `operator<`**：A7 报 `C3889`、A8 又报 `C2676` | 同一个知识点踩两次。记法：**结构体不会自己比大小，比较规则永远要写出来** |
| 4 | **`})` 后面漏 `;`**（A8 连漏 3 次） | 报错行号 ≠ 出错行号（编译器读到下一行才发现上一句没结束） |
| 5 | **拼写滑手**：`viod`→`void`、`cost`→`const`、`dsec`→`desc` | 不靠聪明解决，靠写完扫一眼 |
| 6 | **HTML 里回车不换行** | HTML 把回车和连续空格压成一个空格；换行用 `<br>`，分段写多个 `<p>` |
| 7 | **图片三种写法**：base64 内嵌 → 绝对路径 → 相对路径 | **能显示 ≠ 写对了**。W1 三轮 1300 KB → 4 KB，最后才写对 |
| 8 | **`irm <网址> \| iex`** 拿到 404 网页当脚本执行 | **别闭着眼睛执行网上的代码**；先落地、读一遍、再决定跑不跑 |
| 9 | （我的）**自检脚本三次漏洞**：不认识内嵌图片 / 不认绝对路径 / 比例误报 | 测试只证明"它检查过的那部分是对的"——**自检绿 ≠ 全对**，A8 第 3 段就是这么漏过去的 |
