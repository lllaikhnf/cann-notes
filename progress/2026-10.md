  1. **数组名传参会退化（decay）** —— `int arr[5]` 的 `5` 只是给程序员看的，形参类型会被改写成指针，

`grow` 的五步顺序（关键：顺序错就是悬垂指针或内存泄漏）：

```cpp
int* fresh = new int[newcap];        // ① 申请 cap*2 的新内存
for (i...) fresh[i] = old[i];        // ② 把前 size 个搬过去
cap = newcap;                        // ③ 更新容量（cap 是引用）

```

### 这轮踩的四个坑（都是经典，记下来）

1. **`for` 三段用分号，不是逗号** —— 写成 `for(i=0 , i<n, ++i)` 编译器会报"i 重定义"

3. **`new int{7}` 是"一个" int，`new int[7]` 才是数组** —— 花括号是初值，数组必须方括号

### 2026-10-05 下午 · A8 函数指针 与 lambda

**学了**：函数名**不带括号**是"函数的地址"（`better` 与 `better()` 是两回事）→ 函数能当参数传；函数指针类型 `bool (*cmp)(const Player&, const Player&)`，`*cmp` 外面那对括号不能省；把"比较规则"做成参数的通用 `sortBy`；lambda 语法 `[捕获](参数){ 体 }`；值捕获 `[desc]` 与引用捕获 `[&desc]` 的区别；lambda 的类型是编译器现场造的、拼不出名字，所以只能用 `auto`（或 `std::function`）接。

**本机验证过的演示**：`funcptr-demo.cpp`（`build-funcptr-demo.cmd`）—— 实测输出确认：
- 同一个 `sortBy`，换函数名就是换规则：byScore / byLevel / byLevelDesc 三种顺序
- `cmp(x, y)` 与 `(*cmp)(x, y)` 等价，`sizeof(cmp) == 8`
- 同一个 lambda 一个字没改，外面的 `desc` 从 false 改成 true，升序立刻变降序 —— 这就是捕获的意义
- 反例：规则用 `strlen(name)`（六个人名字一样长）→ 排完顺序没变；**"看起来排序没生效"其实是规则没区分度**
