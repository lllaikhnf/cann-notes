## 二、逐条说

### ① 第 61 行：`if (better(int[j], int[best]) {`

```cpp
if (better(int[j], int[best]) {     // ❌
```

要改成：

```cpp
if (better(a[j], a[best])) {        // ✅ 注意末尾是两个右括号
```

两个问题：

**(a) `int[j]` 应该是 `a[j]`** —— `int` 是**类型**，不是数组。数组在这个函数里叫 `a`：

```cpp
void selectSort(Player a[], int n) {   // ← 形参名是 a
    ...
    for (int j = i + 1; j < n; j++) {
        if (better(a[j], a[best])) best = j;   // ← 所以这里必须写 a[j]
```

> 这条值得记：**函数里只能用形参名**，不能想当然用调用处那个数组的名字（调用处叫 `a` 是巧合，改天叫 `team` 你就得写 `team[j]` 了吗？不，函数里永远是形参名）。
> 顺便复习第十四节：`Player a[]` 这种形参，本质上会被调整成 `Player* a`，**长度同样是丢掉的**，所以 `n` 必须另外传 —— 这题的 `n` 就是这么来的。

**(b) 少一个右括号** —— `if (better(a[j], a[best])` 只关了一个括号，还差一个给 `if`。
所以是 `...a[best])) {`（两个右括号）。

**⚠️ 关键体会**：因为你这两个错，编译器后面报了一大串"离奇"的错：

```
error C3260: “,”: 跳过 lambda 主体之前的意外标记
error C3493: 无法隐式捕获“best”，因为尚未指定默认捕获模式
error C2143: 语法错误: 缺少“)”(在“}”的前面)
```

它甚至以为你在写 lambda（因为 `[j]`、`[best]` 长得像 lambda 的捕获列表）。
**这就是"一个语法错让解析器整段跑偏"** —— 所以永远**只看第一个错误**，改完再编译。

### ② 第 92 行：`std::sort(b, b + 6);`

我单独探了一下（把你 TODO3 修好后只留这行），编译器报的是：

```
error C3889: 对类类型“std::less<void>”的对象的调用: 未找到匹配的调用运算符
note: 二进制“<”:“Player”不定义该运算符或到预定义运算符可接收的类型的转换
        ↑ 报错位置还在 ...\VC\Tools\MSVC\14.44.35207\include\algorithm 里面
```

三个点：

**(a) 少了比较规则。** `std::sort` 传两个参数时，它用默认的 `operator<` 来比 —— 可 `Player` 是我们自己定义的类型，**没有定义 `<`**，所以编不过。
要写三个参数：

```cpp
std::sort(b, b + n, better);
```

**(b) `b + 6` 建议写 `b + n`。** 这题 n 正好是 6，能跑；但哪天数据变成 10 条，这行就悄悄错了。**长度永远用变量，别写死。**

**(c) 记住这条通用经验**：**报错位置指向标准库头文件（`algorithm`、`vector`、`xutility`）时，问题一定在你传给它的东西上** —— 要么类型没定义需要的运算符，要么参数个数/类型不对。别去翻头文件，回头看自己那行。

### ③ 两个小风格点（不影响编译）

## 三、README 四道自测题的答案

1. **n = 100**：选择排序比较次数 = `100 × 99 / 2 = 4950` 次（固定，不看数据）。
   冒泡**最好情况**（数据已经有序）= **n - 1 = 99 次**（第一轮扫一遍发现没交换，提前退出）。
2. `const Player&` 而不是 `Player`：① `&` 避免**拷贝**（结构体越大越值）；② `const` 表明"只读"，调用者放心、也防止自己误改。
3. "等级升序，同等级分数降序"：
   ```cpp
   bool better(const Player& a, const Player& b) {
       if (a.level != b.level) return a.level < b.level;   // 主键换成 level，升序
       return a.score > b.score;                            // 次键换成 score，降序
   }
   ```
4. `better` 后面**没有括号**：因为要传的是**这个函数本身**（函数指针/可调用对象），而不是"调用它的结果"。
   写 `better()` 等于把 `bool` 传进去 —— `std::sort` 需要一个"能比较两个元素的东西"，收到 `bool` 就报错。
   （这正好是 **A8：函数指针与 lambda** 的开场，为什么能这么传、lambda 怎么写，下一节讲透。）
