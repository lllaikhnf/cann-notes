弃垢的学习笔记仓库 —— 主要放 **CANN / 昇腾算子** 这条线的东西：算子、深度学习底层、相关工具链。

## 这个仓库是干什么的

配套计划：**双赛道成长计划（38 周）** —— 一条线走 **应用创新**，一条线走 **CANN 算子开发**。
本仓库装第二条线的内容：

- `progress/` —— 每月的进度记录（学了什么、卡在哪、下一步）
- `notes/` —— 知识点笔记（算子、PyTorch、Linux 等，随学随加）
- `code/` —— 能跑的练习代码（随学随加）
