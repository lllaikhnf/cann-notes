## 二、逐条错误（对着编译器报错看）

### ① 第 12 行：`viod boost(&Player p; int add)`

```cpp
viod boost(&Player p; int add) {   // ❌ 这一行有 3 个错
```

| 你写的 | 应该写 | 为什么 |
| --- | --- | --- |
| `viod` | `void` | 拼写错。编译器**不认识 `viod`** → 报 `C4430 缺少类型说明符`，它以为 `viod` 是变量名。**拼写错是"连锁报错之王"**：这一行后面 5 个错误全是它带出来的 |
| `&Player p` | `Player& p` | **`&` 跟类型走**：`Player&` 是一个整体类型"Player 的引用"，`p` 才是变量名。写成 `Player &p` 也对（& 挨着谁只是排版），但 `&Player p` 是语法错 |
| `;` | `,` | **参数之间用逗号**。用分号 → 编译器以为声明到此结束，于是报 `C2143 缺少 )` |

正确写法：

```cpp
void boost(Player& p, int add) {
    p.score += add;
}
```

（函数体 `p.score += add;` 你写得完全对 ✅ —— 说明"引用能改到原对象"你是懂的，只是签名没写对。）

### ② 第 55 行：`boost(team[i]; 10);`

```cpp
boost(team[i]; 10);   // ❌ 又是分号
```

**调用时实参之间也是逗号**：`boost(team[i], 10);`

👉 **这是这版最值得记的一条**：`;` 和 `,` 你在**同一份代码里错了两处**（函数参数、函数调用）。
而上一次的「扩容练习」你恰好错的是**反方向** —— 在 `for` 的三段里用了逗号。

所以把三个位置钉死：

| 位置 | 用哪个 |
| --- | --- |
| `for ( 初始化 ; 条件 ; 步进 )` | **分号** |
| 函数参数表、函数调用实参 | **逗号** |
| 一条语句结束、`struct` 定义结束 | **分号** |

### ③ 第 66 行：`printf("sizeof(player) = % zu\n", sizeof(player));`

```cpp
sizeof(player)   // ❌ C++ 区分大小写！player 和 Player 是两个名字
% zu             // ❌ 格式符里不能有空格：写 %zu（z 是长度修饰，u 是无符号）
```

正确：

```cpp
printf("sizeof(Player) = %zu\n", sizeof(Player));
```

> 附带一提：编译器这次**没**报 `% zu` 的错 —— 因为格式串是"运行期才检查"的东西（`/W4` 也只能查常量串的明显问题），
> 这种错**编译过了但输出是乱的**，更阴。所以格式符要自己盯紧。

### ④ 小提示：`using namespace std;`

这题全用 `printf`，**不需要它**。这次没坏事，但以后写大程序容易和标准库撞名（比如你自己写个 `count` 变量就炸）。建议不写。

## 三、README 那四道自测题的答案

1. `struct P { char t; int v; char u; };` 的 `sizeof(P)` = **12**。
   `t`(1) + 补 3 + `v`(4) + `u`(1) + 补 3 = 12。不是 6，因为 `int` 要从 4 的倍数地址开始、整个结构体大小要是最大成员（4）的整数倍。
2. `void f(T s)` vs `void f(T& s)`：**看调用处看不出来**（写法一模一样）。判断方法是看**声明/定义**：`T&` 会改到外面，`T` 改的是副本。
   想一眼看出有没有改，可以看函数里有没有对参数赋值，或者干脆养成习惯——只读参数统一写成 `const T&`。
3. 能编译过的：
   ```cpp
   Player a = {"小明", 90, 1};   // ✅
   a.name = "小红";              // ❌ 数组不能整体赋值（char[16] 是数组），要 strcpy 或改用 std::string
   a.score = 80;                 // ✅
   Player b = a;                 // ✅ struct 可以整体拷贝
   ```
4. 各自做不到的一件事：
   - **引用**：不能"先定义后绑定"，也不能改绑到另一个对象（`int& r;` 不合法；`r = y` 是赋值不是改绑）；也不能为空。
   - **指针**：可以改指向、可以为空（所以必须判空），但要解引用、语法更啰嗦。
